# Phase 3 acceptance contract — 2026-09-27

Defined before implementation. Owner explicitly authorizes this experimental phase
with ISO review deferred, superseding the earlier ISO-before-Phase-3 gate. Research
Gate A remains HOLD. ISO 14064-1 licensed-clause review remains UNVERIFIED; no
licensed source is accessed or redistributed. No Phase 4, CarbonDiff or AI work.

## Workflow and acceptance

1. Explicit local canonical JSON packages → existing Pydantic integrity checks →
   collision-checked union → existing RDFLib serializer → packaged SELECT queries →
   sorted JSON or deterministic Turtle. No external service or RDF import.
2. Exact same revision ID may be shared only with identical canonical content.
   Conflicting identities fail before graph construction; never silently union them.
   Quantities have deterministic blank-node IDs derived from record ID and field.
3. Existing PROV-O semantics remain: results were generated by calculations;
   calculations used role-specific inputs. Reviews used their targets, rather than
   generating the result retrospectively. Evidence supports supplied assertions.
4. Five allowlisted, packaged SPARQL SELECT templates: explain_result,
   results_using_factor, records_supported_by_evidence, unreviewed_results,
   revisions. Parameters are validated revision URNs and RDFLib bindings, never
   interpolated. No user SPARQL/file templates, SERVICE, UPDATE, RDF parse or context
   loading. Invalid template, parameter, unknown ID or wrong target kind fails.
5. Revisions follow explicit wasRevisionOf edges in either temporal direction,
   including the seed itself. Benchmark snapshots use distinct logical identities:
   matching row names is NOT proof of revision; no inferred cross-year links.
6. Every one of the 45 clean results across three snapshots resolves calculation,
   activity, source, evidence, factor, factor evidence/version, method/evidence/version,
   GWP/evidence, boundary, inventory/period, review/reviewer/status. Tests use
   independently specified triples and query answer sets, including adversarial
   references, collisions, revision chains, malicious identifiers and CLI failures.
7. CLI adapts draft UX to actual benchmark/generated/2025-v1/package.json and
   full urn:ghgag:...:v1 identities; graph commands read explicit canonical inputs,
   not arbitrary RDF files. No hidden persisted default graph. Errors have stable
   nonzero exit and omit private paths/input contents. Repeated output is identical.
8. Full regression, docs, format/lint, package build, isolated locked reproduction,
   license/vulnerability review, tree/staged/history secret and semantic privacy
   review precede publication. Verify remote SHA/blob hashes and hosted CI. Only
   existing issues #9/#10 may close against fulfilled criteria.

Runtime provenance is a queryable record of stored assertions, not proof of source
truth, completeness of a real inventory, review authenticity, certification or
standards conformity. Independent parent and practitioner review remain necessary.
