# 0.3.0a1 — reported totals without invented lineage

Qualified research alpha; **not** an assurance opinion, certification, v1.0,
research GO decision, DOI archive or journal submission.

## Changes
- Additive reported-disclosure/1 represents public aggregate numeric facts as
  ReportedAssertions with source locators, hashes and explicit unavailable evidence.
- Separate invalid inputs, assessed checks and not-assessable evidence.
- Compare per-series values without double-counting Scope 2 alternatives or totals;
  preserve unknown/changed basis and UNKNOWN causal drivers.
- Full offline CLI ingestion, graph, explanation, comparison, package verification
  and Obsidian export; bounded deterministic evidence actions.
- Incorporate the independent validation, adapter, CarbonDiff and evidence repairs
  made after the prior 0.2.0a1 source version.

## Compatibility
Canonical calculated schema/ontology and ACME benchmark 0.1 remain unchanged.
Existing calculated-result lineage requirements are not relaxed. The new profile
is an explicit alternate input contract, not a silent migration. No new dependency
or hosted AI service is required.

## Limits
Explicit human fact mapping is required; this is not a universal PDF parser or
arbitrary-company assurance system. Missing factors/activity data prevent emission
recalculation; aggregate differences cannot prove causal abatement. Source assurance
statements remain attributed claims. Full reporting coverage, gas detail, controls,
uncertainty, practitioner review and research Gate A remain unresolved.
