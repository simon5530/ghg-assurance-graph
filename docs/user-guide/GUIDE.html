git clone https://github.com/simon5530/ghg-assurance-graph.git
cd ghg-assurance-graph
git rev-parse HEAD
uv sync --locked
uv run python scripts/run_moenv_example.py --out artifacts/moenv-worked

13 / Edit carefully and hand off

The workbook is not an automatic Excel-to-graph importer.

You may edit blue monthly cells in the filled XLSX examples to observe formula recalculation. Fixed source/month blocks must not move. Edits do not rewrite CSV, originals, hashes, canonical results or graphs.

--out regenerates the fixed training scenario; it does not read your edited workbook. --check reads this profile's saved CSV and rejects inconsistent documents or calculations. Arbitrary real-company ingestion requires an explicit mapping, not fictional evidence.
