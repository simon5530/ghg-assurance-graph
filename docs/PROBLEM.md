# Problem

Status: bounded deterministic implementation and public-disclosure examples exist; [Gate A scoped GO](GATE_A.md), not a general novelty or assurance claim.

## Hypothesis, not novelty claim
Organizational GHG results can lose their connection to source evidence, factor
versions, boundary decisions, transformations, and review actions. This project
asks whether an inspectable provenance graph and deterministic change explanation
can improve reproducibility without replacing existing accounting engines.

## Proposed research questions
- RQ1: Can a canonical evidence model trace a reported result to its inputs and decisions?
- RQ2: Can explicit constraints detect seeded evidence defects with measurable false positives?
- RQ3: Can CarbonDiff reconcile inventory deltas with deterministic, reviewable reasons?
- RQ4: Can an independent user reproduce outputs from a versioned evidence package?

Existing tools, standards, and research must be compared before claiming a gap.
Researcher evidence is pending; no superiority or unique-first claim is justified.
Non-goals: a calculator, legal advice, certification, or a production assurance platform.
