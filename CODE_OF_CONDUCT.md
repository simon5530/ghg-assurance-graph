# Code of conduct

Treat participants respectfully regardless of background, identity, or experience.
Critique claims with evidence, not personal attacks. Harassment, threats, doxxing,
and disclosure of confidential organizational or personal information are prohibited.

Maintainers may edit/remove harmful content, limit participation, or block repeat
violations, with proportionate action and an explanation when safe. Maintainers
are bound by the same rules. Report non-sensitive moderation concerns to maintainers
via a minimal issue; never publish incident details or private evidence. A dedicated
private conduct-reporting channel has not yet been established. For security issues,
follow [SECURITY.md](SECURITY.md). Appeals should request an uninvolved reviewer
where one is available; no independent moderation body is currently promised.
